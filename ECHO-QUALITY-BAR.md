# Echo — Quality Bar: Advanced Coding & Real-Looking Results
Jakob's standing rules for all Echo building work. Set 2026-10-14.

## Coding standard
- Advanced, production-quality code only. No placeholders, no toy shortcuts, no half-finished features presented as done.
- Inspect existing project files before changing them. Preserve what works; build in small, reviewable steps.
- Never claim a test, render, or build succeeded unless it actually ran.

## Visual standard — nothing stays blocky
- Blockout models (like the Roblox model kit) are only a starting skeleton — never the finished product.
- Finished models must look real and alive: true proportions, beveled edges, panel and surface detail, correct materials, and lighting that makes them read as real objects.
- Build in passes: blockout → detail pass → materials → lighting → render and compare against Jakob's reference sheets before calling anything done.
- If a result still looks like plain blocks or cheap AI output ("AI slop"), it is not finished. Redo the pass.

## Who sets the bar
Jakob is the creative director. His reference sheets and his storyline documents are the source of truth. When a result and a reference disagree, the reference wins.
